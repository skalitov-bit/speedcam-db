# SpeedCAM — база камер России

Гибридная база камер для SpeedCAM 0.9.32 и новее. При совпадении координат применяется заданный приоритет источников. Тип и модель комплекса сохраняются, если присутствуют в исходных данных.

База выпускается отдельно от приложения, в разделе **Releases**. Приложение проверяет канал при запуске, каждые 6 часов и кнопкой **4 ОБНОВИТЬ БД** на вкладке **КАРТА**.

Канал: https://github.com/skalitov-bit/speedcam-db/releases/latest/download/channel.json

Каждый релиз содержит неизменяемые бинарный индекс, записи и манифест с SHA-256. Канал публикуется после загрузки всех файлов. Приложение активирует базу только после проверки; при ошибке продолжает использовать прежнюю.

Ежедневная подготовка выполняется локальным генератором владельца. Публикация происходит только после успешной загрузки обоих источников и проверки всех записей. При отсутствии изменений новый релиз не нужен. Даты исходных баз указаны в channel.json.

Исходные данные принадлежат их правообладателям. Этот репозиторий не меняет лицензию исходных данных. Границы регионов: © OpenStreetMap contributors, ODbL 1.0. Пароли, ключи, DeviceID и исходные настройки авторизации здесь не хранятся.
