# SpeedCAM — общая гибридная база

База камер России и зарубежных стран для SpeedCAM 0.9.32 и новее. MapCam.info, еСтрелка, RadarBase, Helito и дополнительная грузинская выборка OSM / SpeedAlert / SpeedCams / MapAtlas приводятся к существующему бинарному формату v1 и общим категориям. Изменение программы для обновления базы не требуется; текущая сборка проверена штатным загрузчиком SpeedCAM 0.9.53.

Российская часть поступает из прежних двух источников. RadarBase загружается из 11 выгрузок: AM, AZ, BY, DE, ES, GE, KZ, RS, TR, UA, UZ; RU из него не запрашивается. Названия выгрузок не являются строгими географическими фильтрами, европейские наборы перекрываются. Helito и дополнительная GE-выборка дополняют общий каталог. Полнота покрытия стран не заявляется.

База выпускается отдельно от приложения в [Releases](https://github.com/skalitov-bit/speedcam-db/releases). Приложение проверяет канал при запуске, каждые 6 часов и кнопкой **КАРТА → ОБНОВИТЬ БД**.

[Канал обновления](https://github.com/skalitov-bit/speedcam-db/releases/latest/download/channel.json)

Каждый релиз содержит согласованные индекс, записи и манифест с SHA-256. Все файлы загружаются до публикации релиза. Приложение активирует базу после проверки; при ошибке продолжает использовать прежнюю.

Ежедневная подготовка выполняется локальным генератором владельца в 09:00 по московскому времени. Основные три источника загружаются и проверяются без понижения дат. Проверенные справочные снимки Helito от 13.11.2026 и GE от 11.11.2026 автоматически добавляются при каждой сборке; эти снимки обновляются отдельно. Добавление справочного источника может выпускаться поверх уже проверенной опубликованной базы с сохранением дат её источников. Даты загрузки не означают проверку каждой камеры на местности.

При добавлении Helito/GE объединяются только взаимно однозначные точки разных источников в пределах 3 метров, одного типа и с совместимыми известными лимитами. Неоднозначные соседние объекты сохраняются раздельно. Прежние бинарные записи сохраняются. Исторические записи GE без подтверждения Helito не активируют предупреждения.

Неизвестные лимиты не подменяются. Секционные камеры без геометрии представлены точками: расчёт средней скорости между ними не добавлен. Большинство дорожных опасностей хранится, но не озвучивается текущим движком. Неустановленные направления Helito не используются как направление движения. Старый интерфейс может сохранять подпись «Россия» и служебную метку MapCam; фактическое происхождение дополнений находится в provenance.json и технических метаданных.
