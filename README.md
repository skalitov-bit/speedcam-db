# SpeedCAM — общая база камер

Гибридная база камер России и зарубежных стран для SpeedCAM 0.9.32 и новее. Три исходных источника приводятся к существующему бинарному формату v1 и общему справочнику категорий. Полное чтение проверено на штатном SpeedCAM 0.9.51; отдельное обновление приложения для новой базы не требуется.

Российская часть поступает из прежних двух источников. Дополнительный источник загружается из 11 выгрузок: AM, AZ, BY, DE, ES, GE, KZ, RS, TR, UA, UZ; RU из него не запрашивается. Названия выгрузок не являются строгими географическими фильтрами: европейские наборы перекрываются. Повторы удаляются. Полнота покрытия всех стран мира не заявляется.

База выпускается отдельно от приложения в разделе [Releases](https://github.com/skalitov-bit/speedcam-db/releases). Приложение проверяет канал при запуске, каждые 6 часов и кнопкой **ОБНОВИТЬ БД** на вкладке **КАРТА**.

[Канал обновления](https://github.com/skalitov-bit/speedcam-db/releases/latest/download/channel.json)

Каждый релиз содержит согласованные бинарный индекс, записи и манифест с SHA-256. Сначала загружаются все файлы черновика, затем релиз публикуется. Приложение активирует базу после проверки; при ошибке продолжает использовать прежнюю.

Ежедневная подготовка выполняется локальным генератором владельца в 09:00 по московскому времени. Публикация разрешена только после успешной загрузки всех трёх источников, проверки дат без отката, чтения всех записей и проверки совместимости со штатным приложением. При отсутствии изменений новый релиз не нужен. Даты исходных баз, фактическое происхождение, правила совместимой упаковки и размеры находятся в технических метаданных.

Специальные виды без точного аналога используют общую категорию. Секционные камеры дополнительного источника представлены точками; расчёт средней скорости между ними не добавлен. Условные лимиты и особенности задней съёмки сохраняются в локальном аудите. Оперативные сообщения о кратковременных засадах не включены. Старый интерфейс может сохранять подпись «Россия» и прежнюю служебную метку источника, хотя рабочая база включает зарубежные точки.

Исходные данные принадлежат их правообладателям. Этот репозиторий не меняет лицензию исходных данных. Границы регионов: © OpenStreetMap contributors, ODbL 1.0. Пароли, ключи, DeviceID, приватные исходные выгрузки и настройки авторизации здесь не хранятся.
