# Городские карты SpeedCAM

Необязательная офлайн-подложка дорог. Загружается отдельно через «Настройки → Карты городов». База камер, ограничения скорости и предупреждения остаются отдельными данными.

## Москва и Московская область

Единый пакет: 21 576 531 байт (20,58 MiB). Покрытие — Москва, включая Новую Москву и Зеленоград, и вся Московская область. Исходные административные выгрузки: [OpenStreetMap France — Moscow и Moscow Oblast](https://download.openstreetmap.fr/extracts/russia/central_federal_district/), от 21 ноября 2026 года, 00:08:36 и 00:07:34 UTC соответственно. Дубли дорог удалены по OSM way ID; при совпадении используется более свежая выгрузка Москвы. На границе могут присутствовать продолжения дорог в соседние регионы.

Идентификатор `moscow` сохранён: прежняя городская карта обновляется на единый пакет без добавления второго пункта меню. Содержит дороги и названия улиц; не содержит зданий, поиска адресов или маршрутизации. Приложение читает индексированные участки в области экрана, а не всю область.

Пакет требует поддержки регионального индекса до 2 MiB / 50 000 ячеек, как карта Санкт-Петербурга и Ленинградской области. Фактически индекс занимает 1 473 243 байта и содержит 44 482 ячейки. Данные © OpenStreetMap contributors, ODbL 1.0.

`catalog.json` содержит размер, SHA-256, границы и дату подготовки пакета. Дата подготовки не означает дату обновления каждого объекта OSM. Пакеты именуются по содержимому; обновление устанавливается только после проверки размера, SHA-256 и формата. Рабочая карта сохраняется при ошибке скачивания. Для нового города нужен совместимый пакет и запись каталога. Версия приложения для обновления дорожного пакета не меняется.

Данные © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), доступны по [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Пакет дорог — производная база OSM, распространяется по ODbL 1.0. Сведения об источнике и его SHA-256 находятся также в заголовке файла. При показе карты сохраняйте атрибуцию OpenStreetMap.

## Сборка карт

Генератор: `tools/pack_city_roads.py`, Python 3.11+ и `osmium` (проверено с 4.3.2). Пример сборки Москвы и всей области из папки `maps`:

```sh
python tools/pack_city_roads.py moscow.osm.pbf --extra-pbf moscow_oblast.osm.pbf --out . --id moscow --name "Москва и Московская область" --coverage "Москва, включая Новую Москву и Зеленоград, и вся Московская область" --bbox "34,53,42,58" --source "OpenStreetMap / OSM France: Moscow + Moscow Oblast" --source-url "https://download.openstreetmap.fr/extracts/russia/central_federal_district/"
```

Для Санкт-Петербурга и Ленинградской области:

```sh
python tools/pack_city_roads.py saint_petersburg.osm.pbf --extra-pbf leningrad_oblast.osm.pbf --out . --id saint-petersburg --name "Санкт-Петербург и Ленинградская область" --coverage "Санкт-Петербург и вся Ленинградская область, включая Кронштадт, Петергоф, Пушкин и Колпино" --bbox "27.4,58.35,35.8,61.4" --source "OpenStreetMap / OSM France: Saint Petersburg + Leningrad Oblast" --source-url "https://download.openstreetmap.fr/extracts/russia/northwestern_federal_district/"
```

Выбирайте выгрузки с максимально близким временем данных. При совпадении OSM way ID используется первая запись; более свежую выгрузку передавайте первым аргументом. Генератор проверяет пределы размера индекса, блока и пакета до записи каталога.

Генератор заменяет запись выбранного города, сохраняя остальные записи существующего каталога. Загружайте сначала новый файл с неизменяемым именем, затем новый каталог; лучше одним коммитом. Старые версии можно сохранять для клиентов с закешированным каталогом.
