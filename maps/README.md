# Городские карты SpeedCAM

Необязательная офлайн-подложка дорог. Загружается отдельно через «Настройки → Карты городов». База камер, ограничения скорости и предупреждения остаются отдельными данными.

## Москва

Пакет: 4 147 742 байта (3,96 MiB). Покрытие: 37.32–37.88° в.д., 55.57–55.92° с.ш.; основная часть Москвы, без Новой Москвы и Московской области. Содержит дороги и названия улиц; не содержит зданий, поиска адресов или маршрутизации. Приложение читает индексированные участки в области экрана, а не весь город.

`catalog.json` содержит размер, SHA-256, границы и дату подготовки пакета. Дата подготовки не означает дату обновления каждого объекта OSM. Пакеты именуются по содержимому; обновление устанавливается только после проверки размера, SHA-256 и формата. Рабочая карта сохраняется при ошибке скачивания. Для нового города нужен совместимый пакет и запись каталога. Версия приложения для обновления дорожного пакета не меняется.

Данные © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), доступны по [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Исходная выгрузка: [BBBike Moscow](https://download.bbbike.org/osm/bbbike/Moscow/). Пакет дорог — производная база OSM, распространяется по ODbL 1.0. Сведения об источнике и его SHA-256 находятся также в заголовке файла. При показе карты сохраняйте атрибуцию OpenStreetMap.

Генератор: `tools/pack_city_roads.py`, Python 3.11+ и `osmium` (проверено с 4.3.2). Пример из папки `maps`: `python tools/pack_city_roads.py Moscow.osm.pbf --out .`. Загружайте сначала новый файл с неизменяемым именем, затем новый каталог; лучше одним коммитом. Старые версии можно сохранять для клиентов с закешированным каталогом.
